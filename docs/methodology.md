# Methodology — Ghanaian E-Commerce Brand Perception Analysis

## Purpose
This project examines customer sentiment, trust factors, and perceived market position across five Ghanaian e-commerce platforms.

## Evidence boundary
> Portfolio demonstration repository. The analysis uses synthetic demonstration data generated by the included scripts; it is not a client deliverable or a claim of production campaign performance.

The repository contains public-safe code, generated charts, and documentation only. It does not contain private customer records, confidential company data, credentials, or restricted analytics exports.

## Source categories
The README identifies Trustpilot reviews, Google Play ratings, public social-media discussion, Ghana’s E-Commerce National Strategy 2025–2029, and academic market research as the source categories represented in the prototype. A real-data version would add direct source links, access dates, permissions, collection windows, and a comparability review across platforms.

## Analytical workflow
1. Aggregate platform-level review, rating, and market-context inputs.
2. Classify text sentiment using TextBlob polarity scoring.
3. Compare trust signals across product authenticity, delivery reliability, payment security, customer service, and return policy.
4. Generate charts and a structured executive summary.
5. Separate descriptive findings from interpretation and label generated demonstration values clearly.

## Outputs and reproduction
The script produces trust-score, sentiment-distribution, and trust-factor charts plus `output/ecommerce_executive_summary.json`.

```bash
pip install -r requirements.txt
python scripts/analyze_ecommerce.py
```

## Interpretation and limitations
Generated platform values, trust comparisons, and market-share figures must not be presented as verified customer, market, or company outcomes. Results may also reflect source coverage and measurement choices rather than causal differences in brand quality.
